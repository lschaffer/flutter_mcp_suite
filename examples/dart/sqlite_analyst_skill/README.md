# SQLite Database Analyst Skill (Pure Dart)

Demonstrates how to use `mcp_playground_dart` to execute a multi-turn relational data analytics agent.
The agent discovers the table schemas, formulates and runs analytical SQL queries, aggregates metrics across categories and users, and exports an executive report to `DATABASE_REPORT.md`.

## Features
- Schema auto-discovery tool
- SQL query executor with aggregation logic
- Automatic executive markdown report exporter
- Pure Dart CLI workflow

## Running
```bash
cd examples/dart/sqlite_analyst_skill
dart pub get
dart run main.dart
```
