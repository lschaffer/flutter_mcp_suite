# flutter-a2ui-mcp Skill

AI agent skill for integrating Google's A2UI (Agent-to-User Interface) framework with Model Context Protocol (MCP) in Flutter.

## Quick Summary
- Package: `flutter_a2ui_mcp`
- Replaces: `flutter_genui_mcp` (which used the discontinued `genui` package)
- Architecture: `a2ui_flutter: ^0.3.0`, `a2ui_core: ^0.7.0`, `material_ui`
- Capabilities: Dynamic generative UI, tool calling loop, Agent Inspector, custom component registry.
