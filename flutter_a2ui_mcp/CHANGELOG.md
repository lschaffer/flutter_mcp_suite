## 1.1.0

- **A2UI Ecosystem Upgrade (`a2ui_core ^0.8.0`, `a2ui_flutter ^0.4.0`, `a2ui_agent ^0.4.0`)**:
  - Upgraded `a2ui_core` from `^0.7.0` to `^0.8.0`, `a2ui_flutter` from `^0.3.0` to `^0.4.0`, and `a2ui_agent` from `^0.3.0` to `^0.4.0`.
  - **v1.0 Envelope Normalization & Hardening (`McpA2uiChatController`)**:
    - Added `_sanitizeV1ComponentEnvelope` to guard against `a2ui_core 0.8.0` strict validation errors when models emit `null` `@catalogId`/`catalogId` or mix `@`-prefixed (`@catalogId`, `@metadata`, `@accessibility`, `@checks`) and legacy bare mixin keys on the same component.
    - Stripped leaked `version` keys when transforming direct component shorthand payloads into `updateComponents`.
    - Ensured `createSurface` and component `@catalogId`/`catalogId` normalize unknown or blank catalog IDs to the active catalog ID.
  - **Custom Component Schema Injection & Error Logging (`McpA2uiChatController`)**:
    - Included full JSON schemas of custom domain components in the generated A2UI system prompt so LLMs emit valid property names and required fields instead of guessing.
    - Subscribed to `MessageProcessor.model.onError` and logged A2UI validation/render errors to the Agent Inspector execution log.
    - Added heuristic component inference for `AgentSwarmTimeline`, `SubagentCard`, and `ApprovalGateWidget`.
  - Updated all A2UI example apps to align with `a2ui_core: ^0.8.0` and `a2ui_flutter: ^0.4.0`.

## 1.0.0

- **Initial release of `flutter_a2ui_mcp`**:
  - Successor to `flutter_genui_mcp`, migrated to the modern Flutter A2UI standard (`a2ui_flutter: ^0.3.0`, `a2ui_core: ^0.7.0`, `a2ui_agent: ^0.3.0`).
  - **Dynamic A2UI Surface Rendering**: Renders rich interactive surfaces generated by LLMs inline in conversational transcripts.
  - **Pluggable A2UI Catalog**: Easily register custom components via `A2uiCatalogItemDefinition` and custom functions via `FunctionImplementation`.
  - **Seamless MCP Integration**: Built-in support for remote HTTP/SSE MCP servers, local subprocess servers, and Dart-native tools.
  - **Multi-LLM Support**: Supports OpenAI, Anthropic Claude, Google Gemini, Ollama, Mistral AI, OpenAI-compatible APIs, and local embedded GGUF models.
  - **Agent Inspector**: Real-time side panel for inspecting tool executions, active system prompts, tokens, and A2UI JSON payloads.
  - **Backwards Compatibility**: Includes typedefs (`FlutterGenUiMcp`, `GenuiMcpPlayground`) and compatibility aliases for smooth transition from `flutter_genui_mcp`.
  - **Reactivity & Recursion Guards**: Guarded `updateLlmConfig` and `_onStateChange` against redundant re-entrant state notifications.
  - **Protocol Version Normalization**: Enforces strict A2UI wire protocol version `1.0` and `v0.9` compatibility.
  - **Balanced JSON Scanner & Multi-Surface Extraction**: Robust extraction of concatenated JSON component payloads without regex parsing failures.
  - **Heuristic Component Inference**: Auto-infers component names when models omit the top-level `component` field.
