## 1.0.0

- **Initial release of `flutter_a2ui_mcp`**:
  - Successor to `flutter_genui_mcp`, migrated to the modern Flutter A2UI standard (`a2ui_flutter: ^0.3.0`, `a2ui_core: ^0.7.0`, `a2ui_agent: ^0.3.0`).
  - **Dynamic A2UI Surface Rendering**: Renders rich interactive surfaces generated by LLMs inline in conversational transcripts.
  - **Pluggable A2UI Catalog**: Easily register custom components via `A2uiCatalogItemDefinition` and custom functions via `FunctionImplementation`.
  - **Seamless MCP Integration**: Built-in support for remote HTTP/SSE MCP servers, local subprocess servers, and Dart-native tools.
  - **Multi-LLM Support**: Supports OpenAI, Anthropic Claude, Google Gemini, Ollama, Mistral AI, OpenAI-compatible APIs, and local embedded GGUF models.
  - **Agent Inspector**: Real-time side panel for inspecting tool executions, active system prompts, tokens, and A2UI JSON payloads.
  - **Backwards Compatibility**: Includes typedefs (`FlutterGenUiMcp`, `GenuiMcpPlayground`) and compatibility aliases for smooth transition from `flutter_genui_mcp`.
  - **Reactivity & Recursion Guards**: Guarded `updateLlmConfig` and `_onStateChange` against redundant re-entrant state notifications.
